## Overview

Flowly is a time tracker and task manager built for freelancers and remote workers. It combines task management, built-in timers, calendar sync, and weekly analytics in a single workspace, so solo users can plan the day, track the work, and see where their time went without reconciling separate apps.

## Features

- **Tasks with timers** - Built-in timers, including a Pomodoro mode, attach directly to tasks so logged time maps to real work
- **Multiple views** - Organize tasks in list, kanban, and calendar views, plus a Today dashboard for the current day
- **Weekly analytics** - See where time went across projects and clients, including billable versus total hours
- **Chrome extension** - Capture tasks and start or stop timers from any browser tab
- **Natural-language entry** - Add tasks in plain text such as "draft proposal tomorrow 2pm" and have the date, time, and project parsed automatically
- **Calendar sync** - Two-way sync with external calendars to keep tasks and events in one place
- **AI task suggestions** - Optional AI-assisted suggestions for planning and breaking down work

## Use Cases

- Track billable hours per client without running a separate timer app
- Plan the day and see planned versus actual time at the end of the week
- Replace a Todoist plus Toggl plus calendar plus spreadsheet stack with one tool
