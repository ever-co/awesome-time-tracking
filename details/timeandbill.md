## Description

Time & Bill is a privacy-conscious time tracking application for professionals and teams. It combines web and mobile workflows for tracking project and task time, managing stopwatches, reviewing dashboards, and keeping daily work records organized.

---

## Features

- **Project and task tracking:** Track work time against structured projects and tasks.
- **Web and mobile workflows:** Use Time & Bill in the browser and from the iOS or Android mobile app.
- **Stopwatches and manual entries:** Start stopwatches or add and edit time entries manually.
- **Reports and dashboards:** Review tracked work time and team/project information.
- **Account-based access:** Use managed accounts for team-oriented workflows.
- **Privacy-conscious design:** Built in Germany with clear account-based access and a focus on practical time tracking.
