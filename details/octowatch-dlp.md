## Overview

OctoWatch DLP is a Windows employee monitoring and data loss prevention platform for office, remote, and terminal server (RDS) teams. It combines timesheets and productivity analytics with security-focused capture: app and website usage, screenshots, live view, keystrokes, email/IM, clipboard, USB and file operations, and rule-based blocking with Risks alerts. Deploy as Cloud SaaS or fully on-premise on customer infrastructure.

## Features

### Time Tracking & Productivity
- Active and idle time monitoring
- Timesheets, Chrono timeline, and attendance views
- Productivity categorization and analytics
- Time Tracking edition for softer privacy scope

### Employee Monitoring
- Application and website monitoring with search queries
- Screenshots and video recording
- Live view and remote control (VNC)
- Day viewer / activity timeline for investigations
- Webcam and microphone monitoring (Settings Profile)
- Windows workstations and terminal server sessions

### Data Loss Prevention
- Rules Profile: conditions → notify, block sites/files/USB
- Risks tab and email alerts on policy hits
- OCR content recognition (On-Prem Recognition Server add-on)
- Clipboard, print, and removable media monitoring
- Screen protection / endpoint watermarks

### Platform & Integration
- Cloud Web Console or On-Premise Server + Console
- Floating licenses by active tracked users
- Public Cloud REST API with JWT auth
- Open Node client: [octowatch-api](https://github.com/extralabs/octowatch-api) on npm

## Deployment Options

- **Cloud:** Grabber agent + Web Console at app.octowatchdlp.com
- **On-Premise:** Windows Server + MS SQL, local Web Console, Grabbers on LAN

## Use Cases

- Employee monitoring and workforce analytics
- Insider risk and security investigations
- GDPR/HIPAA-oriented compliance monitoring (on-prem data control)
- Remote and hybrid Windows team visibility
- Terminal server / RDS user monitoring

## Important Notes

OctoWatch DLP is business monitoring software for authorized employer use on company-owned Windows endpoints. Organizations should provide appropriate notice, role-based console access, and comply with local privacy and employment laws. Not Octo Browser.
