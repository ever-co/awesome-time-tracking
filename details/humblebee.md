## Description

HumbleBee is a local-first time tracker for developers, freelancers, consultants, and solo users who want to track work time without a required cloud account. It provides a command-line workflow and a standalone desktop GUI, both using the same local SQLite database.

---

## Features

- **Local-first storage:** Work time is stored in a local SQLite database.
- **CLI workflow:** Start and stop timers, manage projects and tasks, and generate reports from the terminal.
- **Desktop GUI:** Visual workflow for projects, reports, imports, and database switching.
- **Time & Bill import:** Import exported Time & Bill data into a local HumbleBee database.
- **Reports:** Review tracked work time and export tabular data.
- **Open source:** Apache-2.0 licensed Go/Wails application.
